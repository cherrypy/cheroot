The pinned dependency lock files are now applied to the :pypi:`tox`
environments through an in-tree :pypi:`tox` plugin instead of a custom
``pip`` wrapper script, and they are regenerated by a reusable
GitHub Actions workflow shared with other projects. The direct
dependency definitions now live in :file:`dependencies/direct/` and
the lock files in :file:`dependencies/lock-files/`, both named after
the :pypi:`tox` environments using them.
